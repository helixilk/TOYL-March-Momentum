  <action>
    **vite.config.ts** — add the Netlify plugin to the existing config. Import it and add to the plugins array alongside the existing react() plugin:

    ```typescript
    import netlify from "@netlify/vite-plugin";
    // in plugins: [react(), netlify()]
    ```

    Keep all existing config intact (server port 3000, host 0.0.0.0, GEMINI_API_KEY define, @ alias).

    **netlify.toml** — create at project root:

    ```toml
    [build]
      command = "npm run build"
      publish = "dist"
      functions = "netlify/functions"

    [[redirects]]
      from = "/*"
      to = "/index.html"
      status = 200
    ```

    Do NOT add environment variables to netlify.toml — they are build-scope only and NOT available inside functions at runtime. Secrets go in the Netlify dashboard (Functions scope).

    **.env.local.example** — create at project root documenting required env vars:

    ```
    # Copy this file to .env.local and fill in real values
    # .env.local is gitignored — never commit real secrets

    # IMPORTANT: Do NOT prefix these with VITE_ — Vite would inject them
    # into the JS bundle, exposing them to the browser.
    ESPOCRM_API_KEY=your-api-key-from-espocrm-dashboard
    ESPOCRM_BASE_URL=https://crm.yourdomain.com
    ```

    Also verify `.gitignore` includes `.env.local` (it should already; add it if missing).
  </action>
