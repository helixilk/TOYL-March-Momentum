  <action>
    Create the directory `netlify/functions/` and write `submit-lead.mts` using the modern Netlify Functions format (default export, Request/Response, .mts extension). Do NOT use the legacy `exports.handler` Lambda format — Netlify is deprecating it in 2025.

    The function must:

    1. **Method guard** — return 405 for anything other than POST
    2. **Parse body** — `await req.json()` to get `{ firstName, lastName, email, utmSource?, utmMedium?, utmCampaign? }`
    3. **Server-side validation** — return 400 JSON `{ error: "Missing required fields" }` if `lastName` or `email` is absent or empty string. firstName is optional (some people only have one name).
    4. **Read env vars** — `process.env.ESPOCRM_API_KEY` and `process.env.ESPOCRM_BASE_URL`. If either is undefined, return 500 `{ error: "Server misconfiguration" }` — this prevents silent failures in misconfigured deployments.
    5. **EspoCRM POST** — `fetch(`${baseUrl}/api/v1/Lead`, { method: "POST", headers: { "Content-Type": "application/json", "X-Api-Key": apiKey }, body: JSON.stringify({ firstName, lastName, emailAddress: email, source: "Web Site", description: utmSource ? `utm_source=${utmSource} utm_medium=${utmMedium} utm_campaign=${utmCampaign}` : undefined }) })`
       - `source` value must be exactly `"Web Site"` (with space) — it is an enum in EspoCRM and must match exactly
       - `emailAddress` is the EspoCRM field name (not `email`)
    6. **Timeout handling** — wrap the EspoCRM fetch in an AbortSignal with 8-second timeout: `signal: AbortSignal.timeout(8000)`. Catch `AbortError` and return 504 `{ error: "CRM request timed out" }`.
    7. **Upstream error** — if EspoCRM returns non-2xx, return 502 `{ error: "CRM error" }`
    8. **Success** — return 200 `{ success: true }`
    9. **CORS header** — add `"Access-Control-Allow-Origin": "*"` to all responses so local dev (same port via plugin) and future domain changes don't break.

    Type the function using `import type { Context } from "@netlify/functions"` for the second parameter.

    Full function signature:
    ```typescript
    export default async (req: Request, _context: Context): Promise<Response> => { ... }
    ```
