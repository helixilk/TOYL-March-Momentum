```typescript
export {};

interface DataLayerEvent {
  event: string;
  [key: string]: unknown;

    dataLayer: DataLayerEvent[];
  }
}
```

<task type="auto">
  <name>Task 2: Fix Button component to fire onClick when href is also provided</name>
  <files>src/components/Button.tsx</files>
  <action>
The current Button component returns an `<a>` tag early when `href` is set, ignoring `onClick` entirely (lines 32-36). CTA buttons in App.tsx use both `href` (Stripe link) and will need `onClick` (dataLayer push for cta_click tracking).

Modify the `<a>` branch to also call `onClick` if provided:

```tsx
if (href) {
  return (
    <a
      href={href}
      className={combinedClassName}
      target="_blank"
      rel="noopener noreferrer"
      onClick={onClick}
    >
      {children}
    </a>
  );
}
```

This is a one-line addition — just add `onClick={onClick}` to the `<a>` element. The onClick fires the dataLayer push, then the default link navigation proceeds (no preventDefault needed).

Do NOT use any npm analytics packages (no react-gtm-module, no @types/gtag.js). Direct window.dataLayer.push is the standard pattern with GTM.
