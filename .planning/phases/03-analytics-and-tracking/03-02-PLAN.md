<objective>
Wire custom dataLayer events for CTA clicks and waitlist form submissions so GTM can forward them to GA4 (and any future analytics platform) without code changes.

Purpose: These two custom events (cta_click and form_submit) are the conversion tracking layer. Without them, GA4 only sees pageviews — no funnel visibility into engagement or lead capture.

Output: All CTA buttons push `cta_click` events; successful waitlist submissions push `form_submit` events. Both visible in GTM Preview debug panel.
</objective>

  <name>Task 2: Add form_submit dataLayer event to WaitlistForm on success</name>
  <files>src/components/WaitlistForm.tsx</files>
  <action>
In `WaitlistForm.tsx`, add a `dataLayer.push` call in the `handleSubmit` function's try-block, AFTER `await submitLead(...)` resolves successfully and BEFORE `setFormState("success")`.

Change the try-block (currently lines 25-27) to:

```typescript
try {
  await submitLead({ firstName, lastName, email, ...utmParams });
  window.dataLayer.push({ event: 'form_submit', form_name: 'waitlist' });
  setFormState("success");
}
```

Critical placement rules:
- MUST be after `await submitLead()` — only track successful submissions
- MUST be before `setFormState("success")` — ensures push happens before re-render
- MUST be in the try-block, NOT in a useEffect watching formState (research anti-pattern)
- Do NOT add any error handling around the dataLayer push — if GTM is blocked by an ad blocker, the push silently fails (dataLayer is initialized by GTM snippet as an array, and array.push never throws)

Do NOT import any analytics library. `window.dataLayer` is globally typed from `src/types/gtm.d.ts`.
